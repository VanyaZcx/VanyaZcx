## 🐍 Snake Game

A classic Snake game implemented in Python! Play the game where you control a snake that grows longer as it eats food.

### How to Play

1. **Install pygame** (optional, for graphical version):
   ```bash
   pip install pygame
   ```

2. **Run the game**:
   ```bash
   python3 snake.py
   ```

### Controls

- **Arrow keys** or **WASD** to move the snake
- **ESC** to quit
- **SPACE** to restart after game over

### Features

- 🎮 Smooth gameplay with pygame graphics
- 📊 Score tracking
- 🔄 Auto-restart option
- 💻 Fallback text-based version if pygame is not installed

### Game Rules

- Guide the snake to eat the red food
- The snake grows longer with each food eaten
- Avoid hitting the walls or your own tail
- Try to get the highest score possible!

Enjoy playing! 🎉
